# GPT Action Node.js Endpoint

This is a simple Node.js Express server designed to be used as a GPT Action.

## Setup

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Start the server:
    ```bash
    npm start
    ```
    The server runs on `http://localhost:3000`.

## Exposing via Ngrok

To use this with ChatGPT, you need to expose your local server to the internet.

1.  [Install ngrok](https://ngrok.com/download) if you haven't already.
2.  Run ngrok on port 3000:
    ```bash
    ngrok http 3000
    ```
3.  Copy the HTTPS URL generated by ngrok (e.g., `https://random-id.ngrok-free.app`).

## Configuring GPT Action

1.  Go to your GPT in ChatGPT.
2.  Add an Action.
3.  Copy the contents of `openapi.yaml`.
4.  Replace `<your-ngrok-url>` in the `servers` section of the pasted YAML with your actual ngrok URL.
5.  Save and test.
